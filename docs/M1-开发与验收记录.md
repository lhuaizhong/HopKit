## 配置与导航契约

采用 localStorage 保存 M1 的小型无秘密配置库，不引入数据库依赖。后续持久历史由 M11 实现。已有语言/外观偏好与历史键名迁移继续使用 `src/preferences.ts`。

| 键/结构 | schema | 字段与边界 |
| --- | --- | --- |
| `hopkit-navigation` | 1 | `category`、稳定 `tool`、去重后的 `favorites`、三个分类的 `scroll`。未知类别/工具安全回退；滚动值必须有限、非负，并限制到 100,000 |
| `hopkit-library` / JSON 文件 | 1 | `bookmarks`、`profiles`、`configurations`；三张列表各最多 100 项，完整 UTF-8 JSON 最多 256 KiB。名称/ID 最多 120 字符，字符串通常最多 4,096 字符 |
| `TargetBookmark` | 跟随库 | `id`、`name`、`target`；点击后进入网络排障供核对 |
| `Profile` | 跟随库 | `id`、`name`、`snapshot`；按名称保留现场参数，点击后恢复对应工具与模式 |
| `ToolSnapshot` | 1 | `tool`、`mode`、白名单 `values`，以及适用的 `monitor` / `wormhole`。自动配置按工具与模式唯一；最近使用模式排在同工具配置最后，用于重启恢复 |

导入先完整解析和验证，按目标/现场配置 ID 合并、按工具/模式替换自动配置，再对整个合并库验证。格式、未知版本或合并后超限都会拒绝，不留下半导入的库。当前工具/模式的导入设置会同步载入表单；其他设置在切换工具或加载配置时恢复。导入不会触发执行。

FTP 密码、Wormhole 配对码、Syslog 消息正文和未知未来字段不进入配置库。HTTP(S) URL 去掉查询参数和片段，含 userinfo 的 URL 拒绝保存。含 userinfo/query/fragment 的 Wormhole 服务端点不保留。持久配置类型也排除了密码、消息和配对码字段。执行仍使用独立内存中的表单/请求，任务快照不修改执行凭据。密码/配对码需要重新输入，配对码在离开工具时清空。

地址、文件路径、FTP 用户名及用户填写的普通名称仍会保存；M1 不声称可识别所有自由文本中的秘密。完整的导出脱敏预览、映射和 HTML 报告属于 X04-C/D。localStorage 写入失败时显示错误，导航/表单继续可用；无效的未完成输入不会覆盖已验证参数。

## 共用能力与预算的边界

`ToolId` 同时覆盖现有 GUI 工具、`network` / `target` CLI 辅助命令和 `doctor`，语言与导航分类不影响 ID。前端目录不替代 Rust 校验。能力查询描述编译时已有适配器与限制；实际权限和查询失败继续通过运行错误/概览错误返回，不把“有适配器”当作“当前权限已验证”。

批量预算初值与计划一致：默认 32 连接/任务，最大 128/任务和 GUI 合计 128；候选最多 4,096、主机×端口最多 65,536；建议速率 100/任务/秒、合计 200/秒。批量组合用溢出检查计算；共享连接许可在释放或取消后由 RAII 归还。

M1 提供预算和许可接口，扫描/发现/MTR 尚未实现，因此本轮没有启用这些新工具的批量调度或速率器。后续工作包必须接入共享预算、取消等待和限速，不能仅凭接口宣称已有全局限流。原有 iperf3 吞吐量语义不受扫描速率初值限制。既有 Request 保留兼容字段，新工具的专属 Config/Event/Stats/Result 随各工作包增量交付。

## 验证与复现

使用 Node 24、仓库固定 Rust 工具链与锁文件。新增 Playwright 仅为开发测试依赖，产品未增加运行时组件。脚本输出和截图位于忽略提交的 `test-output/m1/`。

```sh
npm run build
npm run test:preferences
npm run test:monitor-range
npm run test:navigation
npm run test:m1-ui
npm run test:wormhole-ui
cargo test --workspace --locked --offline
cargo build -p hopkit-desktop -p hopkit-cli --features hopkit-desktop/custom-protocol,hopkit-desktop/native-test --locked --offline
python3 scripts/m1-native-test.py
target/debug/hopkit-cli --version
target/debug/hopkit-cli doctor --format json
```

`test:m1-ui` 自行启动随机回环端口的 Vite fixture，并在独立无头 Edge 中测试实际 Vue 组件；可用 `HOPKIT_TEST_BROWSER` 指定兼容 Chromium 的可执行文件。fixture 的 IPC 结果属于受控界面测试，协议与原生 IPC 另行验证。内置 Browser 通道本次无法建立可用控制会话，界面验收使用独立 Playwright。
