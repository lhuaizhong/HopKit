# M7 开发与验收记录

日期：2026-11-17；基线 `9bc4158`；源码开发版本 `0.2.0-dev.8`。对应[技术开发计划书 8.2](HopKit-0.2.0-技术开发计划书.md#82-推荐里程碑)的 E06。

本轮完成路径 MTU 的共用核心、CLI、Tauri 和专家工具专属 GUI，交付明确能力边界的开发版。Windows IPv4 使用 DF；Windows IPv6 当前明确返回 `UNSUPPORTED_CAPABILITY`。macOS/Linux 双栈适配器已经接入，仍需各自原生、隔离路由及抓包验收。不能以算法夹具或回环成功代替真实路径验证，不宣称 M7 的所有平台现场门槛已完成。

## 使用与结果语义

专家工具搜索 **MTU / PMTU / 分片 / 包大小**。打开页面、搜索、切换分类和恢复现场配置均不发出探测；必须手动开始。

```sh
hk mtu 192.0.2.10 -4 --min 576 --max 1500 --retries 1 --format json
hk mtu 2001:db8::10 -6 --min 1280 --max 1500 --total-timeout-ms 30000
hk mtu 127.0.0.1 --format jsonl
```

CLI 名称为 `mtu`，内部稳定 ID 为 `pmtu`，action 为 `icmp`，嵌套 `pmtu::Config`、结果和事件 schema 为 1。输入与工具/action 不符时在网络操作前拒绝。地址族明确为 IPv4/IPv6；默认 IPv4，CLI `-6` 默认最小长度 1280。目标可为数字 IP 或域名，禁止 URL 和端口输入。只解析一次，结果保留实际目标和 scope。系统 DNS 最多四个工作线程，遵守本次剩余总期限和既有五秒上限；取消时不等待系统调用返回。

所有长度均为 **IP 包总字节数**：IPv4 无选项为 IP 头 20 + ICMP 头 8 + payload；IPv6 无扩展头为 40 + 8 + payload。界面同时展示上下限换算与每个实际探测的头部/payload 字节数。IPv4 最小 68、默认 576；IPv6 最小 1280；最大 65535。未引入扩展头、网卡 MTU 修改或路由配置修改。

| 字段 | 含义 |
| --- | --- |
| `confirmed_lower` | 重复收到成功回包的最大 IP 长度；没有基线成功时为 null |
| `confirmed_upper` | 有明确 too-big 证据的最小被拒绝 IP 长度；不是“支持的 MTU”，没有明确失败时为 null |
| `reported_mtu` | 最近一次非零设备/内核报告值，独立提示；只有继续发出成功探测才能成为下界 |
| `diagnostic_outcome` | `bounded`：相邻成功/失败长度且通过最终复核；`at_least`：至少支持测试上限；`unknown`：不能形成完成结论 |
| `source` / `local_endpoint` | 用户配置源 IP / 经过路由选择并实际用于 ICMP 绑定的本地 IP；无传输层端口，不保证固定接口 |
| `probes` / `stats` | 有序证据与累计尝试、回包、明确过大、未知数量，时间为 UTC |
| `unknown_reasons` / `partial` | 超时、不可达、路径不一致、总期限、取消、本机错误；取消及错误保留已有证据 |

算法先验证最小长度，再探测最大长度；只有明确 fragmentation-needed、PTB 或本机 EMSGSIZE 才收紧被拒绝上界。已知成功/失败区间内做有限搜索，优先验证有效的报告 MTU 提示。每个成功候选需两次回包；未知响应可使用额外重试（0～3，默认 1），始终不把超时当成过大。搜索出现未知时返回已有部分区间。完成前重复验证成功边界及失败边界，发现矛盾或复核未知时清除不再可确认的边界。所有候选成功只输出“至少支持已测上限”，不会输出精确 PMTU。

ICMP 限速、过滤、ECMP、路由变化和本机缓存均影响观测。即使区间相邻，也仅是本次 ICMP 观测窗口，不保证其他协议或所有流量的有效载荷上限。本机过大证据可能来自接口或内核缓存，不能自动归因于某一远端路由器。

## 平台适配与先行结论

| 平台/地址族 | 实现及能力边界 |
| --- | --- |
| Windows IPv4 | 复用 IP Helper `IcmpSendEcho2Ex`，PMTU 单独设置 `IP_OPTION_INFORMATION.Flags=2`（DF），保持旧 Ping/MTR 的 Flags=0。保留错误状态 11009/10040 为明确过大；此 API 不给 next-hop MTU，字段保持 null。回包关联由系统 API 负责。 |
| Windows IPv6 | 现有 ICMPv6 API 的源端禁止分片没有足够验证证据，能力查询标 unsupported；返回部分空结果和明确错误，绝不回退普通大包 Ping。此项尚未完成受支持实现。 |
| macOS IPv4/IPv6 | ICMP datagram socket 分别设置 `IP_DONTFRAG` / `IPV6_DONTFRAG`；设置失败返回 unsupported。匹配目标、id/sequence、可取得的引用 payload；解析 v4 type 3/code 4 的 16 位 next-hop MTU、v6 PTB 的 32 位 MTU；本机 EMSGSIZE 单独记录。尚未在本机完成 Darwin 原生验收。 |
| Linux IPv4/IPv6 | ping socket 使用 `IP_PMTUDISC_PROBE` / `IPV6_MTU_DISCOVER=IP_PMTUDISC_PROBE`，IPv6 额外设置 DONTFRAG，绕开已缓存 PMTU 的提前拒绝但保留本地接口上限。通过错误队列关联引用探测、目标和 responder，保留 `sock_extended_err.ee_info`。需 ping_group_range 权限；本环境没有可运行 Linux，原生检查待完成。 |

源地址未指定时，以不发送 UDP 报文的 socket connect 取得系统路由选择 IP，再将 ICMP 显式绑定该 IP。不会额外发 UDP 探测；出接口仍可随路由变化。域名输入使用标准化主机名；IPv6 scope 保留。报文解析单测覆盖引用探测不符、截断及报告 MTU，不能作为线上分片行为证明。

没有新增 Rust/npm 第三方依赖，沿用现有 socket2、windows-sys、libc。没有依赖系统 ping、mtr、curl 或其他外部工具执行产品功能。Windows 不需要为此启动管理员 GUI。

## 资源、取消与界面

- 每任务顺序执行，最多 20 次/s，全部重试和复核纳入既有进程共享 200 次/s、128 许可预算，GUI 最多四个活动任务。
- 单次响应期限 100～1000 ms；总期限默认 30000 ms、范围 1000～120000 ms。Unix 每 50 ms 检查取消；Windows 同步调用最坏受单探测 1 秒限制。实际总期限含解析、调度与复核，末尾系统调用及取消检查有有限开销。
- 最多 256 条探测证据，实际有界二分远低于此值；不保存 payload 正文。统计由核心累计，Tauri 专属快照不依赖通用 150 条事件队列。事件序号单调递增。
- 专属结果展示成功/拒绝/报告值、部分状态、原因、协议控制、时间、源 IP 和证据表；长文本转义，表格在容器内横向滚动。支持中英文、两外观、960×680、配置保存/恢复、手动重跑、跨分类停止、JSON/PNG 导出。
- CLI 0：相邻边界或测试上限已复核；1：未知/部分诊断；2：参数；3：权限/能力/资源；4：输出错误；130：主动取消。有限 JSON 与 text/JSONL 共用结果。HTML 仍由 M11 交付。

## 验证与复现

环境：Windows x64、Rust 1.96.0、Node 24；本地回环，无公网探测。本轮独立验证分为纯算法故障注入、字节级 ICMP 错误夹具、Windows 真实回环 ICMP、浏览器与原生 WebView；尚无独立隔离路由对端。

```powershell
npm run build
npm run test:navigation
npm run test:m7-ui
cargo test --workspace --locked --offline -- --test-threads=1
cargo build -p hopkit-cli -p hopkit-desktop --features hopkit-desktop/custom-protocol,hopkit-desktop/native-test --locked --offline
python scripts/m7-integration-test.py
python scripts/m7-native-test.py
```

证据保存于忽略提交的 `test-output/m7/`：`workspace-tests.log`、`build.log`、`integration.json`、`ui.json`、`native.json` 和三张界面截图；CLI/原生记录包含实际版本、平台与二进制 SHA-256。发布流程已接入 `m7-integration-test.py`，不意味着未执行的平台已经通过。
