日期：2026-11-16。基线：`e2dcf51`，源码版本：`0.2.0-dev.7`。对应[技术开发计划书 8.2](HopKit-0.2.0-技术开发计划书.md#82-推荐里程碑)的 E05-A/B/C。

已完成 SNMP v2c/v3 只读核心、CLI、Tauri 与专家工具专属 GUI，包括 GET、GETNEXT、GETBULK、WALK、设备概览和 IF-MIB 接口观察。macOS Apple Silicon 已通过独立 Net-SNMP 对端和原生 WebView 验证；Intel 核心/CLI 交叉编译检查通过。Windows 原生、Intel 原生、两类真实设备和两小时稳定性仍为验收门槛。用户已明确本轮暂不提供真实设备，记录为待现场验收。

## 使用

专家工具搜索 **SNMP / OID / 交换机 / 接口流量**。配置设备、操作和本次运行凭据后手动启动。搜索、载入配置和切换页面不会发出 SNMP 请求。没有 SET、Trap/Inform 或完整 MIB 编译器。

```sh
# 事先通过终端环境或受控启动环境设置相应变量，勿把凭据写进命令参数。
hk snmp get 192.0.2.10 sysName sysUpTime --community-env HOPKIT_SNMP_COMMUNITY
hk snmp walk 192.0.2.10 system --format json
hk snmp overview 192.0.2.10 --snmp-version 3 --username operator \
  --auth-env HOPKIT_SNMP_AUTH_PASSWORD --privacy-env HOPKIT_SNMP_PRIVACY_PASSWORD
hk snmp interfaces 192.0.2.10 --snmp-version 3 --username operator \
  --samples 0 --interval-ms 2000 --format jsonl
```

数值 OID 支持最多 128 个 arc，每个 arc 为 u32；内置符号仅 `sysName`、`sysDescr`、`sysObjectID`、`sysUpTime`、`system`、`ifTable`、`ifXTable`。标量名称包含 `.0`，表名表示子树。GET/GETNEXT/GETBULK 可传最多 32 个 OID，WALK 必须为一个子树。设备概览查询四个 system 标量。

v3 默认 `auth_priv`、SHA-256（RFC 7630，24 字节截断 HMAC）、AES-128-CFB（RFC 3826）。可显式选择 SHA-1 兼容模式（12 字节截断）、authNoPriv 或 noAuthNoPriv；不提供 MD5/DES/AES-192/256。实际安全级别随结果展示，收到降级的普通响应会拒绝，不静默回退。用户名和 context 是无秘密配置；认证和加密密码最少 8 字节。

CLI 仅通过专用环境变量名读取 community/密码，不提供明文凭据参数。GUI Community 在当前页面内存中保留，启动任务后可重复使用；v3 认证/加密密码成功启动后清空。切换工具、恢复配置或重启时清空所有凭据，凭据不持久保存。`Credentials` 为独立运行对象，Request 序列化、Debug、任务快照、前端现场配置和 JSON/PNG 导出均排除凭据。远端字符串通过 Vue 插值和 CLI 控制字符转义展示。远端 OID 的值本身可能包含业务信息，导出前仍应按现场要求检查。

## 协议与资源契约

稳定 ID `snmp`，action 与嵌套 `snmp::Config.operation` 严格匹配，schema 为 1。`snmp_credentials` 仅用于运行，反序列化可接收，序列化永远省略。任务结果包含端点、实际版本/安全级别、engine ID/boots/time、类型化 varbind、对象错误、接口快照、累计统计、完成原因和部分结果标识；PDU 错误 status/index 保留在 `failure.details`。

候选评估：检查了 snmp2 0.5.2 和 rusnmp 0.2.0 的源码。前者的共享不可变输入原地写入和状态更新行为不适合直接接入；后者高层客户端的响应认证/匹配不足，因此**不使用其高层客户端**。固定 `rusnmp = 0.2.0`，仅复用 USM 密码本地化、SHA/AES 和编码原语；HopKit 在 `snmp/ber.rs`、`session.rs` 实现有界解码、响应匹配、USM 状态和可取消 UDP。没有改动或 vendor 新协议库，不依赖系统 Net-SNMP 执行程序运行产品。

协议校验覆盖连接 UDP 对端、v2c 版本/community/request ID、v3 message ID、USM 模型、安全标志、引擎/用户名/context、HMAC、privacy 参数、boots/time 窗口及 scoped request ID。HMAC 验证前不提交引擎状态。首次发现仅接收关联的 unknownEngineIDs Report；已认证 notInTimeWindow Report 最多重同步一次。Report 可按 RFC 3412 使用 request-id 0，普通响应仍必须严格匹配。BER 接受合法非最短定长编码，拒绝不定长、越界、畸形 varbind、溢出计数及尾随数据。

| 项目 | 已实现边界 |
| --- | --- |
| 超时、额外重试 | 默认 1000 ms、1 次；100～10000 ms、0～3 次；UDP 每 50 ms 检查取消 |
| 调度 | 每任务最多 20 请求/s；首次发现、重试和 Report 重同步都使用扫描/发现/MTR 共用的 200/s、128 许可进程预算 |
| WALK | 严格按数值 OID 前进、按 arc 判断子树终点；处理对象异常、endOfMibView、tooBig、空/重复/逆序及不符响应 |
| 结果 | 默认最多 10000 项、4 MiB 解码记录、60 秒总查询期限；可收紧，不能放大；取消和错误保留已经接收的 WALK 项 |
| GETBULK | 默认 max-repetitions 10，范围 1～50；逐列检查前进，限制响应项数 |
| 接口观察 | 默认 2 次、2000 ms；0 次持续；最小 1000 ms；单次完整快照最多 60 秒、512 个接口，慢轮次不排队、不补造采样 |
| 保留 | 最近最多 128 个接口快照，并受解码字节预算限制；淘汰计数独立，累计请求/响应/失败/采样数不从预览反推 |
| GUI | varbind 预览前 1000 项，完整有界结果可导出 JSON；任务中心支持跨分类停止，仍限四个活动任务 |
| 能力边界 | 数字 IPv4/IPv6 或系统解析域名，记录实际 UDP 本地/远端端点；不宣称源 IP/固定接口绑定能力 |

CLI：0 表示完整完成且无对象错误/采样失败；1 表示诊断未满足、超时、PDU/安全错误或结果截断；2 参数/凭据缺失；3 本机权限/能力；4 输出/本机 I/O；130 主动取消。有限 `--format json` 不接受无限接口观察，持续任务用 text/JSONL。JSONL 流式输出压缩的 `snmp_stats` 与最新样本，最后 `finished` 包含完整累计结果和脱敏请求快照。

## 接口速率与缺口

观察 IF-MIB 名称/描述/别名、管理/运行状态、ifSpeed/ifHighSpeed、流量、errors/discards、ifCounterDiscontinuityTime。优先成对 Counter64，缺失时使用 Counter32。所有计数以十进制字符串传给前端；Rust 先做 u64 精确差值再转换 bit/s，使用两次快照的实际单调时间间隔。接口列为顺序查询，不是设备的原子快照，变化剧烈或高延迟设备的估计有采样偏差。

首次采样、sysUpTime 减少/缺失、断点变化/缺失、接口身份或计数宽度变化、计数减少、采样缺口时，速率为空并给出原因。Counter32 在链路速率和采样间隔允许完整回绕、或缺少速率证据时也不生成速率，避免多个回绕被误算成低流量；不猜测回绕次数。

单次超时/网络错误/快照期限到期记录空的缺口样本，继续下一次观察；恢复后的第一次成功采样建立新基线。认证/协议/资源预算错误终止并保留此前快照。单调时间和墙钟发现超过期望至少两秒的采样间隔时标缺口，不把它断言为物理休眠。

## 验证

环境：macOS 27.0.1 Apple Silicon，Rust 1.96.0、Node 24.22.1；独立对端为 Homebrew Net-SNMP 5.9.5.2。macOS 内置 Net-SNMP 5.6.2.1 不支持本次 SHA-2 验证。新增依赖及锁文件检查只增加 SNMP 所需包，既有第三方包版本未升级。

证据保存在忽略提交的 `test-output/m6/`，含平台、源码版本、CLI/原生二进制 SHA-256、检查项及截图。测试均使用回环地址。复现：

```sh
npm run build
npm run test:navigation
npm run test:m6-ui
cargo test --workspace --locked --offline -- --test-threads=1
cargo clippy -p hopkit-core -p hopkit-cli -p hopkit-desktop --locked --offline --no-deps
cargo build -p hopkit-cli -p hopkit-desktop \
  --features hopkit-desktop/custom-protocol,hopkit-desktop/native-test --locked --offline
python3 scripts/m6-integration-test.py
python3 scripts/m6-native-test.py
python3 scripts/m6-soak.py --duration 180
# 现场/长期验收另行执行，不把短测当作通过两小时门槛：
python3 scripts/m6-soak.py --duration 7200
```

Windows/macOS 跨平台 CI 的发布协议回归新增 `m6-integration-test.py --fixtures-only`，使用 release CLI；完整 Net-SNMP 测试通过 `HOPKIT_TEST_SNMPD` 指定独立对端路径。原生测试复用 debug-only 私有存储窗口，不写用户 WebView 偏好；release 禁止启用 native-test。依赖为 MIT/Apache-2.0 及既有 RustCrypto 常用许可，沿用 `build-info.py` 从锁文件生成 notices、原始许可和 SBOM；本次没有生成新发布包。
