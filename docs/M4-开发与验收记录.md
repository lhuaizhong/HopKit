## 交付与使用

### E03 TCP/UDP 调试助手

专家工具的 **TCP / UDP** 支持 TCP connect/listen、UDP send/listen。显示实际本机端点、远端端点、累计字节、UDP 数据报数、发送错误、来源/会话拒绝及预览淘汰计数。监听地址可指定本机 IP；`0.0.0.0`、`::` 表示通配监听，对端应使用相应接口地址连接。可用网络排障首页查看本机地址。

TCP 会话使用本任务内递增 ID，区分接收半关闭、发送半关闭、断连和关闭。选择会话发送、半关闭写方向或关闭；对端半关闭接收后仍可回复。两个方向均关闭后自动释放活动会话名额，编号仍保留在有限历史中。TCP 一次读取称为字节流片段，不称为业务消息。UDP 保留空数据报及各数据报边界；发送成功只表示本机交付，不代表对端收到。

输入支持 UTF-8、HEX、无换行/LF/CRLF、有限重复次数与间隔。HEX 按原始字节确定性展示，包含零字节；UTF-8 不完整或非法时提示查看 HEX。远端内容始终作为文本转义。错误 HEX、错误会话、任务类型不符、已经停止的任务均不能发送。监听者发送 UDP 时必须填写明确数字目的端点；来源 CIDR 同时约束 UDP 监听的收发，拒绝隐式广播回显。自动回显默认关闭，启用须填写允许来源及速率。

每任务一个非阻塞 socket 循环，最多 16 个活动 TCP 会话；每轮每会话至多读 16 KiB、至多收 16 个 UDP 数据报，空闲轮询 5 ms。连接复用既有可取消 TCP transport。停止关闭全部 socket，通用 GUI 仍最多四个活动任务。

| 预算 | 边界 |
| --- | --- |
| 单次发送 | TCP 至多 65,536 字节；UDP 采用保守的 65,507 字节上限（IPv4/IPv6 一致，不支持 jumbogram） |
| 发送计划 | 等候与执行中合计最多 32 项；每项 1～1,000 次，间隔 10～60,000 ms；队列满返回 RESOURCE_EXHAUSTED |
| 发送速率 | 默认每秒最多 10 次，允许 1～100；重复与回显同样受限 |
| 实时预览 | 默认最大 1 MiB 序列化记录预算，且最多 1,000 条；不足时淘汰并累计计数，超大单条跳过预览 |
| 接收/发送统计 | 核心独立累计，不从前端预览反推；发送失败保留最后错误 |
| 正文记录 | 启动前显式填写新 JSONL 路径；默认 16 MiB、最高 1 GiB；不覆盖，达到上限或写入错误停止记录并提示 |
| 连续运行 | 手动停止或至多 86,400 秒有限时长；连接/发送超时 100～10,000 ms |

正文默认仅驻留有限实时内存预览。`socket_state` 获取专用预览；通用任务的 events、请求快照、最终结果、常规 JSON/复制中不包含收发正文。常规 PNG 对此工具禁用，避免把发送编辑器/正文直接放入通用报告。专用“导出预览”默认仅元数据，显式勾选后可导出上方当前显示条数内的正文；该选项不承诺自动识别或清除业务秘密。现场配置不保存报文、记录路径或自动回显授权；重启不自动启动网络任务。

CLI 示例（`hk` 是分发时的短入口，开发目录可用 `target/debug/hopkit-cli`）：

```sh
hk socket tcp connect 127.0.0.1 9000 --input text
hk socket tcp listen --listen 127.0.0.1 --port 9000 --input jsonl --format jsonl
hk socket udp send 127.0.0.1 9000 --hex 00ff01 --duration 2 --format json
hk socket udp listen --listen ::1 --port 9000 --allow ::1/128 --duration 10 --format jsonl
```

输入模式为 none/text/hex/raw/jsonl。raw 从 stdin 最多读 64 KiB；text/hex 每行一个计划；jsonl 可带 session_id、destination、encoding、data、newline、count、interval_ms、operation。stdin 和 stdout 是独立通道，stdout 的 JSONL 每行均是一个对象，携带一致的 task_id 与 schema_version，最终行包含脱敏参数快照。交互输入错误会停止任务并返回参数错误；Ctrl+C 返回 130。JSON 要求有限 duration；JSONL 可持续运行。正文输入推荐 stdin，避免命令行历史或进程列表泄露。

```json
{"operation":"send","session_id":1,"destination":null,"encoding":"hex","data":"00ff01","newline":"none","count":2,"interval_ms":1000}
```

CLI text/JSONL 的收发记录包含正文预览，适合显式现场调试；最终结果仍只有元数据。有限运行完成退出 0，发送失败通过 stats.send_errors/last_error 表示，不把退出 0 当作对端收到。参数 2、本机权限/资源/端口冲突 3、文件/输出错误 4、取消 130。

### U02 本机端口与连接

小工具的 **Connections** 为只读视图，支持协议、地址族、端口、PID、状态、地址片段及进程名片段过滤，50 项分页。默认手动刷新；可选每 2 秒刷新，上一查询未完成时不重叠。查询不占网络探测任务名额，不能终止进程、释放端口或修改防火墙。

Windows 使用 `GetExtendedTcpTable`/`GetExtendedUdpTable` OWNER_PID 表，分别查询 IPv4/IPv6；进程名来自 ToolHelp 进程快照，不采集完整路径。保留 TCP 状态、IPv6 scope、通配地址、PID 和可得进程名；UDP 没有 TCP 状态。进程退出、PID 复用和权限导致的名称不确定性在说明中明确。四张表顺序读取，不承诺原子一致；结果包含开始/结束 UTC 时间、耗时和 partial_errors。

系统查询最多两个工作线程，前台每 50 ms 检查取消、5 秒超时；超时后尚未返回的 OS 调用继续占许可，直至真正结束。每张表最多 8 MiB、65,536 行，最多三次处理表增长重试；超限/失败显示错误，不伪造空表成功。

macOS 提供系统 `/usr/sbin/lsof -nP -i -FpcfPtTn` 适配器，固定参数、无 shell、4 秒子进程期限和 4 MiB 输出上限，支持结构化字段、IPv4/IPv6 通配监听解析。能力明确为 partial：进程/端点可见性受权限影响，即便空结果也不能断言系统没有监听。**此适配器本轮只有解析样本测试，没有 macOS 原生验收。** Linux CLI 使用有界 `/proc/net/tcp{,6}`、`udp{,6}`，不提供 PID/进程归属并明确部分可见。

服务任务返回 ADDRESS_IN_USE 时，结果区提供“查看端口占用”，仅预填端口，查询须手动操作。不按同端口猜测本应用 task_id，不提供未经证明的任务链接。

```sh
hk connections --listening --port 8080 --format json
hk connections --protocol tcp --state established --process hopkit
```

### U03 Wake-on-LAN

小工具的 **Wake-on-LAN** 支持常见 MAC 格式，标准化为大写冒号格式；拒绝零地址、组播/广播目标 MAC。构造严格 102 字节 Magic Packet（六个 FF 加 16 次 MAC），显式开启 UDP 广播。IPv4 数字目的地址、源绑定、端口、次数/间隔可调，默认 9/3 次/200 ms；次数最多 100，间隔 10～60,000 ms，可取消。

“读取接口广播建议”只查本机；选择后依接口实际前缀计算广播，例如 `192.0.2.2/23` 得 `192.0.3.255`，不假定 /24，/31、/32 不提供广播建议。源绑定只保证源 IP，不强制路由出接口。结果保留实际源端点、目的、尝试、发出、错误、UTC 与耗时，不存在 wake_success 字段。

```sh
hk wol AA:BB:CC:DD:EE:02 --broadcast 192.0.3.255 --source 192.0.2.2 --port 9
```
