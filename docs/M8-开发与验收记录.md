# M8 开发与验收记录

日期：2026-11-17；基线 `728eaa5`；源码开发版本 `0.2.0-dev.9`。对应[技术开发计划书 8.2](HopKit-0.2.0-技术开发计划书.md#82-推荐里程碑)的 E07-A/B。

已交付 DHCPv4 只读配置检查和有限主动发现的核心、CLI、Tauri、专属 GUI、配置与导出。Windows 本机只读、标准端口独立对端、真实网卡无 Offer 及独立广播对端已验。**物理 DHCP 设备、隔离网络抓包、多网卡负向验证和 macOS 原生验收尚未完成，因此 M8 的全部发布门槛仍未满足。** 本记录不将测试对端、回环或构建成功等同于这些现场门槛。

## 使用和结果

专家工具搜索 DHCP / 租约。手动检查后，点击结果中的按钮预填接口，再手动开始发现。导航、搜索、参数恢复及预填不自动发包；重启清除网络相关接口选择，显式加载现场配置可恢复。配置模式、时间、次数和预期服务器清单均经过白名单校验，未知字段不持久化。

```sh
hk dhcp inspect --format json
hk dhcp inspect --interface 8
hk dhcp discover --interface 8 --duration 5 --attempts 3 --expected-server 192.168.1.1 --format json
```

接口支持 inspect 返回的稳定 ID、名称或当前索引。索引会变化；重名/歧义和不存在的接口明确报错，不自动改用其他接口。macOS 使用网络服务 ID，BSD 接口名也可匹配；同名多服务存在时须选唯一服务 ID。

- 配置：`operation=inspect/discover`、`interface`、`duration_secs`、`attempts`、`expected_servers`；嵌套于 Request.dhcp，内部 tool ID 为 `dhcp`，action 与 operation 必须匹配。
- 结果：schema 1，UTC 起止时间、耗时、接口/配置来源、租约字段、Offer、server_ids、累计统计、事务 ID、客户端 MAC、本地绑定与广播目的地址、诊断结果、partial 和限制。配置是系统顺序快照，不宣称原子一致。
- Offer：server identifier 与实际报文来源分别保留，yiaddr/siaddr、租期、掩码、路由器、DNS、搜索域、giaddr 和 option 82 的有界十六进制证据；没有预期清单时 outside_expected 为 null。
- 诊断：`configuration_observed`、`offers_observed`、`outside_expected_observed`、`no_offer_observed` 或错误/取消时的 `unknown`。无 Offer 不证明没有 DHCP 服务器；清单外仅表示用户清单比较，多个 Offer 可来自合法冗余。
- CLI：0 为配置检查完成，或收到有效 Offer 且无结果预算缺失（含清单外）；1 为无 Offer/超预算部分结果；2 参数；3 本机能力、权限、端口或资源；4 I/O/输出；130 主动取消。执行状态和诊断结果分开，无 Offer 的窗口可执行完成且退出 1。
- `local_endpoint=0.0.0.0:68` 是通配接收绑定，**不代表线上源 IP 为 0.0.0.0**。此 UDP 适配器使用指定接口系统栈选择的源 IPv4，真实网卡对端观察到本机配置的地址；未配置地址接口的互通尚未验收。

## 平台和协议

| 适配器 | 实现与边界 |
| --- | --- |
| Windows 只读 | IP Helper `GetAdaptersInfo` 读取 IPv4、掩码、网关、DHCP 开关、可取得的服务器及租约开始/到期；`GetAdaptersAddresses(AF_INET)` 读取友好名称、有效 DNS 和连接后缀。静态接口的 DHCP 服务器/租约为 null；空/零/广播服务器不冒充有效值。DNS/后缀可能含手动设置，不一概认定为 DHCP 下发；当前连接后缀不等于完整系统搜索策略。无需 CIM、PowerShell 输出解析或外部安装工具。 |
| macOS 只读 | SystemConfiguration 动态存储的 Setup IPv4 方法及 State IPv4/DNS/DHCP；LeaseStartTime/LeaseExpirationTime 为 CFDate，Option_54 为数据字段；缺失为 unknown。只使用固定参数 `/sbin/ifconfig <系统枚举接口>` 取得 MAC。未读取陈旧租约文件；已实现适配代码，尚无本轮 macOS 原生编译/运行证据。 |
| Windows 发现 | socket2 UDP，独占 0.0.0.0:68，不设置端口复用；IP_UNICAST_IF 固定发送接口，IP_IFLIST/IP_ADD_IFLIST 限制接收接口，广播至 255.255.255.255:67。标准端口冲突/权限不足明确失败，并保留已经读到的接口配置。未接管或停止系统 DHCP 客户端。 |
| macOS 发现 | UDP 68→67，IP_BOUND_IF 绑定选定接口；不复用标准端口。受权限及系统客户端占用影响，原生和报文验收待完成。 |
| 其他平台 | inspect 明确返回 unsupported；不以租约文件或空结果假装支持。核心协议编解码仍可测试。 |

发送器仅构造 DHCPDISCOVER，广播标志置位、ciaddr 为零，事务 ID 来自随机 UUID，chaddr 和 option 61 关联当前接口的六字节单播 MAC。同一窗口复用同一事务，不发送 DHCPREQUEST/RELEASE/DECLINE、不申请地址、不修改配置。DISCOVER 可能使服务器临时预留 Offer 地址；界面及帮助均有说明。

接收器要求标准来源 UDP 67，校验 BOOTREPLY、Ethernet htype/hlen、magic cookie、xid、chaddr、Offer 类型、server identifier 与 yiaddr；若回送 client-id 必须匹配。截断、非法选项长度、无效掩码和无效服务器地址计入 malformed；无关事务/客户端/消息计入 ignored。RFC 3396 的分段选项先有界合并，再校验单值长度；重复单值不会静默覆盖。支持 option overload、option 119 有界向后压缩指针解析；循环/越界拒绝。未知选项有界读取，不执行远端内容。

默认收集 5 秒、最多 3 次发送；配置范围 1～30 秒、1～3 次。收集窗口从配置读取与 socket 建立后开始；总耗时含系统查询。每次 I/O 最多等待 50 ms，所有循环检查取消。最多保留 256 个唯一 Offer，同 server/yiaddr/报文来源/relay 的重发计入 duplicates；超预算累计丢弃数并置 partial，不能宣称结果完整。单包最大 4096 字节，单选项合并上限 2048 字节。Winsock 对超长 UDP 的 WSAEMSGSIZE 计入畸形报文并继续收集。

接口读取最多两个独立工作线程；5 秒等待上限，50 ms 检查取消，未完成系统调用继续持有线程许可直到返回。接口最多 128 项，API 缓冲最多 2 MiB；避免取消后无限创建线程。GUI 保留四任务上限；标准端口独占进一步限制单进程/系统上的同时发现。发送最多 3 次/秒，不需要扫描连接的高并发调度。

Tauri 使用有界专属快照，统计不依赖通用事件队列；事件序号单调递增。停止/权限/端口等错误保留已有配置与 Offer。GUI 展示来源、未知值、清单比较、relay、累计统计和限制；远端内容用 Vue 文本插值。JSON 保留完整有界结果，PNG 表格按卡片宽度排版。支持中英文、两种外观、960×680、任务中心跨分类停止。HTML 由 M11 交付。

## 验证与复现

Windows x64，Rust 1.96.0、Node 24。没有新增 Rust/npm 第三方依赖、更新第三方锁文件或生成发布安装包。

```powershell
npm run build
npm run test:navigation
npm run test:m8-ui
cargo test --workspace --locked --offline -- --test-threads=1
cargo build -p hopkit-cli -p hopkit-desktop --features hopkit-desktop/custom-protocol,hopkit-desktop/native-test --locked --offline
python scripts/m8-integration-test.py
python scripts/m8-native-test.py
# 仅在选定测试网络主动发送，按实际 inspect ID 调整：
python scripts/m8-integration-test.py --live-interface 8
python scripts/m8-peer-test.py --interface 8
```

主动广播夹具明确要求静态 IPv4 测试接口，只对匹配本机 MAC、完整测试 DISCOVER 指纹的事务回复，不向其他客户端提供服务。默认 integration 和发布工作流只做只读检查，不在 CI 网络自动广播。测试端口 67/68 如被真实服务占用，应在测试环境处理，不能停止系统 DHCP 客户端来通过测试。

| 检查 | 已取得证据 |
| --- | --- |
| 工作区回归 | 165 项通过，0 失败：CLI 13、core 单元 114（含 DHCP 12）、core 集成 37、Tauri 1。含超长报文、取消及 256 条保留/44 条截断的预算验证。 |
| 协议字节 | DISCOVER 的精确报文、无 REQUEST/RELEASE/DECLINE 构造；事务/MAC/client-id 不符、截断、重复单值、RFC 3396 合并、overload、域搜索压缩与循环、relay、预期清单比较、参数/请求不符和提前取消。 |
| 标准端口独立回环 | 使用标准 127.0.0.1:67 与独占 UDP 68，独立构造两个 server ID 的 Offer；核对来源端口、广播标志、300 字节 DISCOVER；错误事务、短包、5000 字节超长报文、重复 Offer 均按统计处理；窗口取消在 500 ms 断言内返回并保留 Offer。此用例只在 Windows 原生运行，不以高端口测试替代。 |
| 真实网卡 | 当前静态 IPv4 接口一轮 3 秒/1 次 DISCOVER，无匹配 Offer，返回 no_offer_observed/退出 1；前后系统地址、DNS、租约字段一致。占用 UDP 68 后返回明确本机错误/退出 3、sent=0，保留只读信息。 |
| 独立广播对端 | 在该网卡标准 UDP 67 接收一次真实 DISCOVER，独立编码两个广播 Offer 到 UDP 68；HopKit 收到两个唯一 Offer，server ID、报文来源、relay 和清单内/外字段正确。`peer.json` 保存收到的 payload 十六进制和 CLI 结果。对端仍是本机测试夹具，不是物理 DHCP 设备。 |
| 浏览器 | 6 组检查：不隐式查询、显式接口预填、未知/来源、Offer 与恶意文本转义、取消保留 JSON/实际 PNG、工具往返/重启、双语两外观、最小窗口及跨分类全局停止。导出图片与界面截图已目视检查。 |
| 原生 GUI | 独立 incognito 测试存储，真实表单 → Rust IPC → 系统只读；接口预填不自动执行；占用标准端口时发现表单保留配置/sent=0；请求不匹配和接口不存在明确失败。 |

证据位于忽略提交的 `test-output/m8/`：workspace-tests.log、dhcp-tests.log、build.log、clippy.log、integration.json、peer.json、ui.json、native.json、导出 PNG 与三张界面截图。JSON 记录实际二进制版本和 SHA-256。Clippy 完成，告警位于既有代码及第三方；没有新增依赖。

## 仍需完成的 M8 发布/现场门槛

- 物理 DHCP 服务端/设备的单、多服务器与 relay 互通；真实 DHCP 和静态配置、有效/过期租约、手动 DNS 覆盖及权限场景。
- 隔离网络独立抓包，确认实际出接口、源 IP、广播、事务/客户端匹配，证明没有 REQUEST/RELEASE/DECLINE；至少两网卡的错误接口负向测试。当前 PktMon 驱动查询在沙箱及申请工具提权后均返回“拒绝访问”，没有取得线上抓包，不能宣称已通过。
- 未配置 IPv4 的接口：当前 UDP 栈适配不能保证 DHCP INIT 所需的零源 IP；在标准设备验证前不扩大支持声明。如需 raw/BPF 特权适配应独立实现和验收。
- macOS Apple Silicon/Intel 原生编译、动态存储字段、端口占用/权限、IP_BOUND_IF 收发与取消。Windows 上编译未包含框架 FFI 分支，不作为 macOS 编译证据。
- 长时组合资源测量和发布安装包验收。256 Offer 纯结果预算测试已通过，尚未取得隔离网络规模验收证据。
